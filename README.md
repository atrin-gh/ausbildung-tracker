Ausbildung Tracker

A simple command-line application built with Python to manage Ausbildung applications.

Features
• Add new applications
• View all saved applications
• Search applications by company name
• Update application status
• Delete applications with confirmation
• Save application data in a JSON file

Technologies
• Python
• JSON
• Git

How to Run
1. Install Python 3.
2. Download or clone this repository.
3. Open a terminal in the project folder.
4. Run:
python main.py

Application Statuses
• Beworben
• Vorstellungsgespräch
• Absage
• Zusage

About
This project was created as a practical Python learning project to improve programming skills, work with JSON data, and build a useful command-line application.
